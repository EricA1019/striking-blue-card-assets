# Remi “Bugs” Landry — Card Assets

Asset folder for **Remi “Bugs” Landry | Soft Heart, Bloody Hands** by Striking-Blue.

## Primary / Greeting Images

Upload images with these exact filenames:

- `portrait.png` — original front-facing card portrait
- `caught-in-the-act.png` — Caught in the Act route
- `original-offer.png` — romantic/original-offer route
- `professor-bugs.png` — Professor Bugs / LISA student route
- `old-friend.png` — Old Friend / Corner Hollow route
- `disappearance.png` — Someone Made Them Disappear route
- `investigator.png` — Too Many Coincidences / investigator route

## Creator Notes / CSS Extras

Place optional decorative images under `extras/` with descriptive filenames, for example:

- `lisa-lecture.png`
- `botanical-study.png`

## Intended URL Pattern

Once this repository is public, assets can be referenced directly with raw GitHub URLs such as:

`https://raw.githubusercontent.com/EricA1019/striking-blue-card-assets/main/cards/remi-bugs-landry/portrait.png`

The card should keep the original Remi artwork as the main portrait; route images are tied only to their matching greetings.
